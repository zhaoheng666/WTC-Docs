## 一、赛季名称配置检查（seanNameConfig）

### 背景

荣誉榜页面 `CardRankHonorPageController.js` 新增了赛季名称显示功能：赛季名与年份是**两个不同字体的 label**，数据来源于文件顶部手动维护的 `seanNameConfig`。赛季更新时容易遗漏该配置，故在 Skill 中加入检查与提醒。

### 关联代码实现（S25 期间）

| 改动点 | 内容 |
|--------|------|
| CCB 绑定修复 | `card_ranking_honor_page.ccb` 原两个 label 均绑定为 `_lbName`（加载时后者覆盖前者），已将年份 label（`card_ranking_font_2.fnt`）改绑为 `_lbYear`，赛季名 label（`card_ranking_font_3.fnt`）保留 `_lbName` |
| 成员声明 | 构造器新增 `this._lbName = null;`、`this._lbYear = null;` |
| 文本拆分 | `initWith` 中用正则 `/^(.*?)\s*(\d{4})$/` 将配置值拆成赛季名 + 年份 |
| 大写处理 | 赛季名 `toUpperCase()` 后再设置（`card_ranking_font_3.fnt` 不含小写字符） |
| 文本设置 | 统一使用项目封装 `game.nodeHelper.setNodeText()`（带节点有效性检查和 BMFont dirty 标记修复） |
| 动态排版 | 年份 x 坐标 = `_lbName` 右边缘（中心 x + 宽度 ×(1-锚点x)）+ 间距 + `_lbYear` 半宽，在设置文本后计算 |

**配置格式**（值为「赛季名称 年份」，年份 4 位数字结尾）：

```javascript
var seanNameConfig = {
    24: "Summer of Honor 2026",
    25: "Harvest of the Heart 2026"
}
```

### Skill 新增流程（阶段 1.2）

1. 代码调整阶段，检查 `seanNameConfig` 是否已有 `{新赛季ID}: "..."` 条目
2. 已存在 → 继续；缺失 → **不阻断流程**，仅记录
3. 阶段 8 完成摘要输出后，若缺失则用 ANSI 红色（`\033[1;31m`）在控制台输出提醒，内容包含：
   - 文件路径：`src/social/controller/card_system/card_rank/CardRankHonorPageController.js`
   - 配置格式示例
   - 补充后需重新构建生效
4. 赛季名称以卡牌计划文档/运营提供为准，AI 不自行编造，仅提醒用户补充
