# 关卡背景音乐（BGM）配置

关卡 BGM 的播放节奏由 `machineConfig.classicAudioMode` 一个开关决定，框架提供两套预设。
**遇到"BGM 该不该在落定时停"这类需求，先确认当前是哪种模式，不要去写 AudioComponent / SpinUIComponent 的子类。**

相关框架文件：

```txt
src/newdesign_slot/component/AudioComponent.js
src/newdesign_slot/component/SpinUIComponent.js      // stopSpinBgMusic
src/newdesign_slot/process/SubRoundStartProcess.js   // updateMusicVolume
src/newdesign_slot/process/WaitForSpinProcess.js     // 挂机 10 秒淡出
```

---

## 两种模式的差异

| 行为 | Classic（`classicAudioMode = true`） | 非 Classic（`= false`） |
| --- | --- | --- |
| **落定时** | base BGM 无条件 `stopMusic()` | `stopSpinBgMusic` 整个方法被开关挡住，**不停** |
| **是否循环** | base 不循环（播一遍就完），free / respin 由 `supportFreeSpinBgMusicLoop` / `supportRespinBgMusicLoop` 控制 | `getBgMusicLoop` 直接返回 `true`，**默认全循环** |
| **BGM 文件名** | 由配置指定：`spinBgMusic` / `freeSpinBgMusic` / `respinBgMusic` | **框架写死**，见下方文件名约定 |
| **是否在播的判定** | 看 `currentBGMState` 状态机 | 比对 `game.audioPlayer.curMusic` 是不是那几个固定名字 |
| **挂机 10 秒** | 不受影响 | 会 `fadeOutMusic` 淡出，需 `forcePlayMusicInWait` 关掉 |

一句话：**Classic = "spin 开始播、落定停"，非 Classic = "一直循环播"。**

---

## 需求 → 该选哪种模式

| 需求 | 配置 |
| --- | --- |
| BGM 跟着 spin 走，落定就停 | `classicAudioMode = true` |
| BGM 一直播不停 | `classicAudioMode = false` |

### 非 Classic 模式的完整配置

```javascript
slotMachineScene.machineConfig.classicAudioMode = false;
slotMachineScene.machineConfig.supportClassicBgMusic = false;
slotMachineScene.machineConfig.forcePlayMusicInWait = true; // 跳过挂机 10 秒淡出
```

同时要把音效资源**改成框架写死的文件名**，放在 `res_xxx/关卡资源目录/audio/` 下：

| 文件名 | 用途 |
| --- | --- |
| `bg_music` | base BGM |
| `free_spin_bg_music` | freeSpin BGM |
| `bonus_game_bg_music` | bonus 玩法 BGM（需手动指定播放，见下） |
| `bonusgame_bgm` | 同上，另一个可用名 |

非 Classic 模式下 `getBgMusicPath()` 只认这几个名字，`spinBgMusic` 之类的配置**完全不生效**。

## 特殊玩法（respin / pick / bonus）的 BGM

非 Classic 模式没有 `respinBgMusic` 这类配置，特殊玩法的 BGM 需要在对应 action 里手动切：

```javascript
// 进入玩法：forcePlay = true 强制切换，forceLoop = true 循环
this.context.audioComponent.playBackgroundMusic(false, true, "bonus_game_bg_music", 0, true, true);

// 退出玩法：停掉，让下一轮 SubRoundStartProcess 自然播回 base BGM
this.context.audioComponent.stopMusic();
```

`playBackgroundMusic` 参数：

```text
playBackgroundMusic(isFreeSpin, forcePlay, musicName, startTime, forceLoop, isRespin)
```

**退出玩法一定要配对调用 `stopMusic()`**：`SubRoundStartProcess.updateMusicVolume` 只在"当前没有 BGM 在播"时才重新播放，不复位的话玩法 BGM 会一直循环到 base 里。

## 注意事项

### forcePlayMusicInWait 可能不生效

`WaitForSpinProcess` 读的是 **AudioComponent 的实例属性**：

```javascript
if (this.audioComponent && !this.audioComponent.forcePlayMusicInWait)
    this.audioComponent.fadeOutMusic(null, null, true);
```

而配置写的是 `machineConfig.forcePlayMusicInWait`，框架里**没有把配置同步进组件的地方**（`updateForcePlayMusicInWait()` 的调用点全是注释）。
如果实测挂机 10 秒后 BGM 仍然淡出，在场景 `afterInitialize` 里补一句：

```javascript
this.audioComponent.updateForcePlayMusicInWait(true);
```

### 会让 BGM 从头重播的地方

`currentBGMState` / 当前音乐只有被 `stopMusic()` 才复位，以下几处会导致 base BGM 重头播，属于框架既有行为：

| 时机 | 位置 |
| --- | --- |
| bigWin 前后 | `WinEffectComponent`（先停、播完再恢复） |
| freeSpin 进 / 出 | `FreeSpinAction` |
| 特殊玩法进 / 出 | 关卡自己的 action |

## 案例：308 Phantom Panther

需求是"base BGM 一直播，不是落定就停"。原本是 Classic 模式，改法：

1. 配置里 Classic 那一段整段注释掉，换成非 Classic 三行
2. 音效资源改名为 `bg_music` / `free_spin_bg_music` / `bonus_game_bg_music`
3. respin BGM 在 `PhantomPantherTriggerRespinAction.closeTriggerRespinView` 手动播 `bonus_game_bg_music`，在 `PhantomPantherRespinEndAction.showLinkEndView` 里 `stopMusic()` 复位

```txt
src/newdesign_slot/scene/308_phantom_panther/PhantomPantherMachineConfig308.js
src/newdesign_slot/scene/308_phantom_panther/308_action/PhantomPantherTriggerRespinAction.js
src/newdesign_slot/scene/308_phantom_panther/308_action/PhantomPantherRespinEndAction.js
```

同类写法可参考 `JingleJackpotMachineScene`（非 Classic + 手动播 bonus BGM）。
